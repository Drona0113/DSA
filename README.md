# DSA

A structured collection of Data Structures & Algorithms problems solved in **Java**, following [Striver's A2Z DSA Sheet](https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/) with problems sourced from LeetCode.

This isn't coursework — it's engineering practice. Every problem here is solved, tested, and revisited with an eye toward writing clean, correct, production-style logic.

## Why this repo exists

As a backend/full-stack developer, strong DSA fundamentals directly translate to writing efficient, scalable code — not just clearing interviews. This repo is my ongoing practice log, built for:

- Reinforcing core CS fundamentals with real, hands-on implementation
- Building interview readiness for SDE / AI Engineer roles
- Creating a searchable reference of patterns and approaches I've internalized

Each folder maps to a topic from Striver's A2Z sheet. Every problem file includes:
- Problem statement / LeetCode link
- Brute-force approach (if applicable)
- Optimized solution
- Notes on the pattern/technique used
